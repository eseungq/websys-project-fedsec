# web — 웹 시스템

| 폴더 | 역할 |
|---|---|
| `fl_server/` | 연합학습 서버 (Flask). 클라이언트가 쓰는 프로토콜 API: 모델 다운로드, 업데이트 제출, 검증(라운드·모델 버전·클라이언트 ID, 중복 제출) |
| `lab_api/` | (확장 후보) 실험 관리 API. 실험 생성·실행·상태 조회, 결과 비교 등 |
| `frontend/` | (확장 후보) 실험 관리 화면. 라운드별 그래프, 클라이언트 채택 현황 등 |

- 실험 관리 기능을 만들 경우 작업 실행은 작업 큐 1개 + 워커 1개로 단순하게 유지합니다 (Celery·Redis 불필요).
- 모든 통신은 같은 PC의 localhost에서 이뤄집니다.
