# web — 웹 시스템

| 폴더 | 역할 |
|---|---|
| `fl_server/` | 연합학습 서버 (Flask). 클라이언트가 쓰는 프로토콜 API: 모델 다운로드, 업데이트 제출, 검증(라운드·모델 버전·클라이언트 ID, 중복 제출) |
| `lab_api/` | 웹 실험실 API (Flask Blueprint). 실험 생성·실행·상태 조회, 실험 분기, 결과 비교 |
| `frontend/` | 웹 실험실 화면. 실행 이력, 라운드별 그래프, 클라이언트 채택 현황, 두 실험 비교 |

- 작업 실행은 작업 큐 1개 + 워커 1개로 단순하게 유지합니다 (Celery·Redis 사용하지 않음).
- 모든 통신은 같은 PC의 localhost에서 이뤄집니다.
