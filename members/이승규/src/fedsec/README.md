# src/fedsec — 실험 엔진

웹과 독립적으로 동작하는 순수 Python 패키지입니다. 웹(`web/`)은 이 패키지를 호출만 합니다.

| 모듈 | 역할 |
|---|---|
| `data/` | CIFAR-10 로드, 클라이언트 분할(IID / 레이블 편향, 표본 수 유지), 참여·지연 일정 생성 |
| `models/` | 학습용 CNN, DLG용 LeNet |
| `client/` | 가상 클라이언트: 전역 모델 받기 → 로컬 학습 → 업데이트(가중치 차이) 계산 |
| `aggregation/` | FedAvg, 노름 클리핑, 좌표별 중앙값 (텐서 목록 → 텐서, 순수 함수) |
| `attacks/` | 내부자 협력 공격(−5배), DLG 복원 |
| `defenses/` | 가우시안 노이즈 |
| `logger/` | 학습 로그, 복원 로그 기록 |
| `analysis/` | 공격 피해·방어 개선·정상 손실 계산, 그래프 |
| `experiment/` | 설정 로드, 시드 고정, 실험 실행·분기(특정 라운드부터 재실행) |

> 규칙: 방어 함수(`aggregation/`, `defenses/`)는 악성 ID 정답을 인자로 받지 않습니다.
