| 폴더 | 조원 |
|---|---|
| [`조준협/`](조준협/README.md) | 조준협 |

## 규칙
- **자기 폴더만** 수정합니다.
- 다른 조원 폴더의 코드를 import하지 않습니다.
- 데이터 분할은 공용 파일 `configs/splits/iid_seed0.json`을 씁니다.
- 데이터, 모델 파일(`*.pt`), 노트북 출력은 커밋하지 않습니다.
- 공개 코드를 가져오면 원본 LICENSE와 출처를 폴더에 같이 둡니다.
- 폴더 안의 코드 파일·하위 폴더 이름은 영문으로 씁니다.

## 각자 README 형식
`members/<이름>/README.md`에 아래 항목을 씁니다. 11/24에 이 README들을 나란히 놓고 비교합니다.

| 항목 | 내용 |
|---|---|
| 구현 범위 | 명세 몇 단계까지 구현했는지 |
| 실행 명령 | 설치부터 실행까지 그대로 복사해 쓸 수 있는 명령 |
| 설정 값 | 모델, 옵티마이저, 학습률, round, local_ep, local_bs 등 |
| 결과 | 정확도, 시간, 시드 |
| 커밋 ID | 결과를 낸 코드의 커밋 |

## 한글 폴더 주의
- macOS: `git config --global core.precomposeunicode true`
  - 한글 이름의 자모가 분리되어 저장되면 같은 이름이 다른 폴더로 인식됩니다. 이를 막습니다.
- `git status`에 한글이 `\354…`처럼 보이면: `git config --global core.quotepath false`
