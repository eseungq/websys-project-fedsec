## 명세 핵심 요약
- Flask 서버 1개 + 한 프로그램에서 순차 학습하는 가상 클라이언트 10개, REST API로 모델 다운로드·업데이트 제출
- 업데이트 = 로컬 학습 후 가중치 − 시작 전역 가중치, FedAvg는 표본 수 가중 평균
- 내부자 협력 공격: 악성 2명, 참여한 악성들의 정상 업데이트 평균 × (−5)를 각자 제출
- 방어: 노름 클리핑 + FedAvg, 좌표별 중앙값 (방어 함수에 악성 ID 정답 전달 금지)
- 모델 역추적: DLG, 이미지 1장의 1회 그래디언트, 가우시안 노이즈(없음·작음·큼) 방어
- 환경: 기준 / 지연(고정 3명) / 부분 참여(10명 중 5명) / 레이블 편향(표본 수 유지)
- 채택 0개면 비율 N/A, 3개 미만이면 모델 갱신 안 함
