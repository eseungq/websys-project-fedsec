# decisions — 설계 결정 기록

팀이 정해야 하는 값과 그 근거를 하나씩 기록합니다. 보고서의 "실험 설정" 절에 그대로 활용합니다.

파일 이름: `NNN-주제.md` (예: `001-model-choice.md`)

## 템플릿
```
# NNN. 제목
- 날짜 / 결정자:
- 상태: 제안 | 확정 | 변경됨(→ NNN)

## 배경
## 선택지
## 결정
## 근거 (참고한 실험·로그)
```

## 결정해야 할 항목
- [ ] 모델 구조 (BatchNorm 사용 여부 포함)
- [ ] 데이터 사용량, 학습·검증·테스트 분할 비율
- [ ] 라운드 수, 로컬 epoch, 학습률, 배치 크기
- [ ] 레이블 편향 구성 방식
- [ ] 클리핑 상한 (정상 실험 참고, 전체 비교에서 고정)
- [ ] 중앙값 집계 전 클리핑 적용 여부
- [ ] 가상 지연 시간과 마감 시각, 지연 클라이언트 3명
- [ ] 노이즈 σ (작음·큼), DLG 이미지와 복원 반복 횟수
- [ ] 시드 개수
- [ ] 클라이언트별 성능 정의 (분포 가중 정확도 등)
- [ ] 확장 방향
